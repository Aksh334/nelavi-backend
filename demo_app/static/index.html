Run the integrated workflow

Main workflow

One run, four stages: image findings, research, a compute summary and a synthesis. Each stage is skipped, run by a labelled FAKE stand-in on this machine, or run by the real provider this server was started with. A real provider is used only for a stage you set to Real and only when you press Run; a provider being configured never means it has been called. A real stage is offered only when the server confirms it is configured, and a failed stage is reported as failed, never replaced by a fake.

The synthesis stage needs both the image and the research stage to finish; it is skipped otherwise. A synthesis is generated text, not evidence, and never replaces a finding. The specialist role has no definition yet and is always skipped.

1. Describe the run

Crop, region and growth stage are optional. They are never guessed, and blank is fine.

2. Choose how each stage runs

If no image is chosen, the fake image stage uses a built-in 1 by 1 placeholder picture and ignores it anyway: the fake stand-in never looks at an image.

What this run will do

    This list shows your current choices. Nothing is sent anywhere until you press Run, and only the stages set to Real contact a provider. Each run saves one new simulated Record to the history (Section 4); the older runner in Section 1 saves its own Record separately.
